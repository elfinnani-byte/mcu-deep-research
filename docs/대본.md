# 🎬 대본 — 자막과 대사 순서

> 2026-09-23 · `q1-기본` 을 실제로 재생하며 `world.convo.push` 와 `world.caption` 을
> 런타임에서 가로채 받아 적은 것이다. 기억으로 쓰지 않았다.
> 앞머리 두 줄(①기획·②배정)만 훅을 걸기 전에 지나가서 `script.js` 를 직접 호출해 뽑았다.
>
> 문장이 만들어지는 곳은 [`web/js/script.js`](../web/js/script.js) 한 파일뿐이다.

**두 층으로 되어 있다.**

| | 인칭 | 자리 | 하는 일 |
|---|---|---|---|
| **자막** | 3인칭 해설 | 무대 위 띠 | 무슨 일이 벌어졌나 |
| **대사** | 1인칭 | 캐릭터 머리 위 말풍선 | 누가 무슨 말을 하나 |

**파이프라인은 이 문장들을 모른다.** 이벤트 스키마를 건드리지 않고 말만 고칠 수 있게 떼어 놨다.
그래서 대본을 바꿔도 **녹화 22편을 다시 뜰 필요가 없다.**

실측 분량 — 자막 **26줄** · 대사 **25줄** (`q1-기본`, 재위임 없는 1바퀴 실행).

---

## ① 기획 — 편집장 혼자, 자기 자리에서

```
▸ 자막 [질문을 받았다]  질문을 받았습니다. 편집장이 서고 51건의 목록을 훑습니다.
▸ 자막 [목차를 나눴다]  편집장이 질문을 5개의 절로 나눴습니다. 서사 축으로 보기로 했습니다.

  대사 편집장 ·  질문에 대해 고민하고 5절로 나눴습니다
```

아직 회의가 아니다. 편집장은 제 책상에 앉아 있다.

## ② 배정 — 아직 혼자

```
▸ 자막 [문서를 배정했다]  절마다 먼저 읽을 문서를 정했습니다. 남이 맡은 문서는 서로 피합니다.

  대사 편집장 ·  먼저 읽을 문서도 정했습니다
  대사 편집장 ·  결재를 올리겠습니다
```

**「결재를 올리겠습니다」는 배정까지 끝난 뒤에 나온다.** 교재 5강이 사람에게 확인하라고 한
세 가지 중 둘이 배정에 관한 것이고, *"코드 검증은 형식만 봅니다 — 그게 질문에 맞는 문서인지는
확인하지 못해요"* 라고 못 박았기 때문이다. 결재 대상은 **목차 + 배정** 둘 다다.

## 🔏 결재 — 사람이 멈춰 세운다

```
▸ 자막 [결재 대기]  여기서 멈춥니다. 목차와 배정이 맞는지 사람이 봐야 합니다
                  — 기자가 한번 나가면 되돌릴 수 없습니다.
```

모달에 체크리스트 세 줄이 뜬다 (교재 5강). 앞의 둘은 코드가 판정하고, 셋째는 사람 몫이다.

**승인이면**

```
▸ 자막 [승인]  승인이 났습니다. 기자들이 출발합니다.

  대사 편집장 ·  승인이 났습니다. 다들 회의 탁자로 모여 주세요      ← 여기서 모인다 (1.9초)
```

**반려면**

```
▸ 자막 [반려]  반려됐습니다 — {사유}. 목차부터 다시 짭니다.

  대사 편집장 ·  반려됐습니다 — {사유}. 다시 짜겠습니다             ← 자리에 그대로
```

## ③ 파견 — 업무분장 회의

```
▸ 자막 [파견]  기자 5명이 동시에 출발합니다. 서로 무엇을 읽는지 모릅니다.

  대사 편집장 ·  이번에는 서사 축으로 봅니다
  대사 편집장 ·  질문을 5갈래로 나눴습니다 — 큰그림·시간순·인물·원인·비교
  대사 편집장 ·  업무분장 하겠습니다
  대사 편집장 ·  김기자는 [큰그림] 「1. 인피니티 스톤의 기원과 첫 등장」
  대사 편집장 ·  이기자는 [시간순] 「2. 각 스톤의 주요 사건과 연관성」
  대사 편집장 ·  박기자는 [인물] 「3. 인물들의 역할과 사건의 전개」
  대사 편집장 ·  최기자는 [원인] 「4. 사건의 원인 분석」
  대사 편집장 ·  정기자는 [비교] 「5. 인피니티 스톤의 영향과 결과」
  대사 편집장 ·  나눠준 문서를 먼저 확인하세요          ← 이 줄에서 쪽지 5장이 차례로 날아간다
  대사 편집장 ·  이후에는 남이 보는 문서는 피해서 보세요
  대사 편집장 ·  서로 무엇을 읽는지 모릅니다
  대사 편집장 ·  각자 업무를 진행하고, 업무가 끝나면 보고합니다
  대사 전원   ·  네. 알겠습니다                        ← 말이 끝나야 흩어진다 (1.4초)
```

**시작 문서는 말하지 않는다.** 07강이 *"조사관들은 서로를 볼 수 없습니다 … A를 보낼 때
'B·C·D는 이 문서들을 맡았으니 너는 그쪽 말고' 라고 일러 줄 수 있어요"* 라고 했다.
개별 배정은 각자에게만 가고, 공통 규칙만 회의에서 말한다 — 그래서 쪽지다.

**절제 스위치가 대사를 바꾼다.**

| 끈 것 | 바뀌는 줄 |
|---|---|
| 역할 | 축 줄과 `[명찰]` 이 통째로 빠진다 |
| 구역 | `이번엔 남의 문서를 피하지 않습니다 — 겹쳐도 그대로 둡니다` |

## ③ 조사 — 각자 서고에서, 자막만

말풍선은 없고 자막만 흐른다. 읽을 때마다 한 줄씩. `q1-기본` 에서 이 구간만 **18줄**이다.

```
▸ 자막 [빈손]    박기자가 「마블 스튜디오 · 개요」 — 이 절과 관련이 없어 빈손으로 나왔습니다.
▸ 자막 [읽었다]  김기자가 「인피니티 스톤」 33,206자를 읽고 메모만 들고 나왔습니다.
▸ 자막 [읽었다]  정기자가 「MCU 페이즈 3」 38,811자를 읽고 메모만 들고 나왔습니다.
▸ 자막 [읽었다]  이기자가 「MCU 페이즈 1」 26,436자를 읽고 메모만 들고 나왔습니다.
▸ 자막 [읽었다]  최기자가 「MCU 페이즈 2」 21,125자를 읽고 메모만 들고 나왔습니다.
▸ 자막 [읽었다]  박기자가 「어벤져스: 인피니티 워」 54,731자를 읽고 메모만 들고 나왔습니다.
▸ 자막 [원고]    이기자가 원고 622자를 썼습니다 · 출처 2곳.
▸ 자막 [원고]    박기자가 원고 327자를 썼습니다 · 출처 1곳.
            … (읽기·원고가 섞여 이어진다)
▸ 자막 [원고]    김기자가 원고 1,044자를 썼습니다 · 출처 11곳.
```

*"메모만 들고 나왔습니다"* 는 격리를 말한 것이다 — 원문 33,206자는 기자 안에서 끝나고
위로는 메모만 올라간다.

근거를 하나도 못 찾으면 `[근거 없음] {이름}의 절은 근거를 한 곳도 못 찾았습니다.` 가 나온다.

> **여기 겹침이 보인다.** 「어벤져스: 인피니티 워」를 박기자와 정기자가 둘 다 읽었다.
> 시작 문서는 안 겹치는데(0건) 돌아다니다 겹친다 — 미해결 과제 2번.

## ④ 점검 — 다시 모여 보고

```
▸ 자막 [점검 통과]  점검을 지납니다 — 빈 칸 없음.

  대사 편집장 ·  다들 모여 주세요. 보고 받겠습니다                 ← 다시 모인다 (1.6초)
  대사 김기자 ·  「인피니티 스톤의 기원과 첫 등장」 1,044자 · 출처 11곳 찾았습니다
  대사 이기자 ·  「각 스톤의 주요 사건과 연관성」 622자 · 출처 2곳 찾았습니다
  대사 박기자 ·  「인물들의 역할과 사건의 전개」 327자 · 출처 1곳 찾았습니다
  대사 최기자 ·  「사건의 원인 분석」 1,300자 · 출처 12곳 찾았습니다
  대사 정기자 ·  「인피니티 스톤의 영향과 결과」 1,206자 · 출처 8곳 찾았습니다
  대사 편집장 ·  모든 절에 근거가 붙었습니다. 제가 정리하겠습니다
```

회의 탁자 위의 램프가 이때 켜진다 — 🟢 통과 / 🟠 빈 절 있음.

**빈 절이 있으면** 마지막 줄이 이렇게 바뀌고 2바퀴째가 돈다.

```
▸ 자막 [되돌림]  빈 절 1개를 ②로 되돌려 보냅니다.

  대사 편집장 ·  {절 이름} 가 비었습니다 — 다시 다녀오세요
  대사 편집장 ·  {N}명만 다시 다녀오세요                          ← 재파견
  대사 전원   ·  네. 알겠습니다
```

근거를 못 찾은 기자는 `「{절}」 근거를 못 찾았습니다` 로 보고한다.

## ⑤⑥ 종합과 완료

```
▸ 자막 [종합]  편집장이 5개 절을 묶어 5,044자 보고서를 썼습니다 — 원문은 보지 않습니다.

  대사 편집장 ·  저는 원문을 안 봤습니다. 각자 요약만 받았습니다
  대사 편집장 ·  5개 절을 한 편으로 묶었습니다 — 5,044자

▸ 자막 [평가]  정답표 없이 지표 7개로 쟀습니다 — 근거가 달린 문장 61.8%.
▸ 자막 [완료]  보고서가 나왔습니다. 58.7초 · 모델 호출 30회.

  대사 편집장 ·  보고서 5,044자가 나왔습니다. 수고하셨습니다
  대사 편집장 ·  근거가 달린 문장 61.8% · 지어낸 인용 0곳 — 이대로 올리겠습니다
                                                        ← 말이 끝나면 각자 자리로 (1.6초)
```

`[평가]` 자막이 뜨면 오른쪽 **대시보드가 저절로 펼쳐진다.**
`[완료]` 에서 최계량 책상 위 칸에 원고가 꽂히고 🔴**발행** 도장이 찍힌다.

## 연출 규칙

| 규칙 | 값 | 왜 |
|---|---|---|
| **한 번에 한 명만 말한다** | — | 각자 큐를 돌리면 다섯이 동시에 떠들어 회의로 안 보인다 |
| 말풍선은 타자로 친다 | `CPS = 26` 자/초 | 한 줄을 다 친 뒤 `HOLD = 0.8` 초 머문다 |
| **대사 중에는 재생을 멈춘다** | `queue.hold` | 짧으면 회의로 안 보인다 |
| 배속은 말·걸음에 똑같이 | `dt × speed` | 대사만 빨라지면 걸어가는 중에 회의가 끝난다 |
| 모이기 | 1.9초(승인) · 1.6초(보고) | 이동이 곧 "지금 회의 중"이라는 신호다 |
| 흩어지기 | 1.4초(파견) · 1.6초(마무리) | `afterTalk` — 대사 큐가 비어야 움직인다 |
| 쪽지 | 0.42초 간격 · 각 0.9초 | 한꺼번에 뿌리면 뭉쳐 보인다 |

## 대본 고치는 법

`script.js` 의 export 만 건드리면 된다. 다른 파일은 손댈 필요가 없다.

| export | 나오는 곳 |
|---|---|
| `caption(w, e)` | 자막 13종 전부 |
| `기획혼잣말` `배정혼잣말` | ①② 자기 자리 |
| `반려대사` `소집대사` `재소집대사` | 🔏 결재 결과 · 회의 소집 |
| `회의대사(w, e, 메모)` | ③ 업무분장 (세 번째 인자가 쪽지 발사) |
| `재파견대사` | 2바퀴째 |
| `점검대사` | ④ 보고 |
| `종합대사` `마무리대사` | ⑤ 이후 |

## 남은 군더더기

**말이 한 번 겹친다.** 편집장이 자기 자리에서 *"질문에 대해 고민하고 5절로 나눴습니다"* 라고
해 놓고, 회의 둘째 줄에서 다시 *"질문을 5갈래로 나눴습니다"* 라고 한다.

회의를 여는 말로 자연스럽다고 볼 수도 있고, 군더더기로 볼 수도 있다.
빼려면 `회의대사()` 의 해당 줄을 지우면 된다.
