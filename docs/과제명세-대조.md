#### 두 번째 원고 — 결정하지 않고 지나온 자리

명세 원문: *"무조건 덮어쓰면 **인용을 빠뜨린 원고가 멀쩡한 원고를 지웁니다.**"*

`server/pipeline.py:238` `절모음()` 은 같은 절이 두 번 올라오면 **마지막 것만** 남긴다.
지금까지 안 물린 이유는 실측으로 분명하다.

```
재위임으로 두 번 올라온 절: 3개 (녹화 22편 전체)
  q1-반려   1절  인용 0 ↑ 1    자수 287 → 488
  q4-기본   1절  인용 0 → 0    자수  68 → 426
  q4-역할끔  1절  인용 0 → 0    자수  56 → 397
```

**세 건 모두 1바퀴 인용이 0곳이라 잃을 것이 없었다.**
그런데 `인용0곳점검`(커밋 `fda1a90`)이 재위임 대상을 **3건 → 최대 21건**으로 늘린다.
이제는 「더 나쁜 2번째가 멀쩡한 1번째를 지우는」 일이 실제로 생길 수 있다.
