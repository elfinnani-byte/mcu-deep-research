# 마블 리서치 데스크

질문 하나를 던지면 **AI 편집장이 목차를 짜고, AI 기자 5명이 동시에 자료를 읽어 각자 한 절씩 써 오고,
빈 곳을 찾아 다시 보내는** 딥리서치 에이전트다. 그리고 그 과정을 **아이소메트릭 사무실**로 보여준다.

> 코퍼스는 MCU 영문 위키백과 **51건 · 1,543,251자** — 모델 창의 약 **3배**다.
> 그래서 하나가 다 읽고 쓰는 방식이 아예 불가능하다.

```
① 기획 → ② 배정 → 🔏 결재 → ③ 조사 ×5 → ④ 점검 →(↺ ②로)→ ⑤ 종합 → ⑥ 평가
편집장    편집장     당신      기자 5명 동시   편집장              편집장     최계량
```

**키가 없어도 전부 볼 수 있다.** 실제로 돌린 기록 **34편** + 혼자 하는 대조군 **5편**이 들어 있다.

📄 **과제 보고서 [`REPORT.md`](REPORT.md)** — 무엇을 만들었고, 무엇을 쟀고, **무엇을 틀렸는지**

![무대](docs/캡처/1-무대.png)

두 기자가 같은 문서를 읽으면 막대가 두 색으로 갈리고(중복), 읽었는데 쓸 게 없었으면 끊어진다(헛읽음).</sub>

## 바로 보기

```bash
cd web && python serve.py      # http://127.0.0.1:8765
```

정적 파일만 있으면 되므로 아무 웹서버나 된다. `serve.py` 는 캐시를 끄고,
배포판의 서버리스 함수(`api/*.py`)를 **같은 코드로** 로컬에서도 태운다.

| | |
|---|---|
| **재생** | 녹화 34편. `질문 × 설정` 두 축으로 골라 **대조군끼리 견준다** |
| **라이브** | 본인 OpenAI 키를 넣고 질문을 직접 돌린다. 키는 **이 브라우저에만** 저장되고 서버에 안 남는다 |
| **🔏 결재** | ② 배정이 끝나면 **사람이 멈춰 세운다.** 승인하면 기자가 나가고, 반려하면 목차부터 다시 짠다 |
| **대시보드** | 정답표 없이 재는 지표 9개 — 근거 · 인용 · 분담 · 격리 |

주소로도 부른다 — `?replay=` `?tab=` `?speed=` `?auto=0` `?report=1`.
예: [`?replay=q4-역할끔&report=1`](https://mcu-deep-research.vercel.app/?replay=q4-%EC%97%AD%ED%95%A0%EB%81%94&report=1)

## 재 본 것

장치를 하나씩 꺼 보고 무엇이 실제로 값을 하는지 잰다. 정답표도 판정 모델도 쓰지 않는다.

| 물음 | 답 |
|---|---|
| **구역을 나누는 것이 값을 하나** | ✅ **한다.** 끄면 5/5 질문에서 중복률이 오른다 (q3는 15번 읽어 문서 3건만 봤다) |
| **역할(명찰)이 값을 하나** | ⏳ **판단 보류.** 칸당 3회로 재니 차이(12~13%p)가 **잡음(14.3%p)보다 작다** |
| **재위임이 값을 하나** | ⚠ **판정 불가.** 방향이 질문마다 뒤집힌다 |
| **팀이 혼자보다 나은가** | ⚠ **못 가렸다.** 근거율 방향이 질문마다 뒤집히고 둘 다 잡음 안이다 |

n=1 표에서는 「5/5 전부 역할 끈 쪽이 낫다」로 보였다. 그래서 반복을 돌리기 **전에**
[`docs/사전등록.md`](docs/사전등록.md) 에 판정 규칙을 못박고, 집계는
[`tools/반복분석.py`](tools/반복분석.py) 가 그 규칙을 코드로 돌리게 했다.
3회가 안 차면 **스스로 판정을 거부한다.**

```bash
python tools/반복분석.py     # 표 + H1 판정
python tools/팀대혼자.py     # 팀 vs 혼자 (차이 옆에 흔들림 폭을 같이 찍는다)
```

**숫자로는 아무것도 못 가렸다.** 그래서 보고서 전문 5편을 읽고 판단을 적었다 —
[`docs/읽고-판단.md`](docs/읽고-판단.md). q5에서는 **근거율이 팀의 두 배인데 읽으면 혼자가 낫다.**

## 구조

```
Source ──> EventQueue ──> Choreographer ──> World ──> Renderer
(기록|라이브)  (배속·정지)     (이벤트→상태)    (상태만)   (캔버스)
```

**의미 이벤트 13종이 유일한 계약이다.** 그림·대사·배치를 바꿔도 녹화를 다시 뜨지 않는다.
**파이프라인은 파이썬 하나뿐이다** — 라이브도 `server/pipeline.py` 를 쓴다.

| 폴더 | |
|---|---|
| `corpus.json` | 문서 51건 + 링크. **손으로 고치지 않는다** — `build_corpus.py` 로 다시 만든다 |
| `data/` | [질문 8건](data/questions.json) — 유형(단일·다갈래·추적)과 「왜 나눌 만한가」. 질문은 **여기 한 곳**에만 |
| `server/` | 파이프라인 · 녹화([`batch`](server/batch.py)·[`repeat`](server/repeat.py)) · [혼자 대조군](server/baseline.py) |
| `api/` | 서버리스 함수 둘 — `/api/plan`(결재 앞에서 멈춤) · `/api/run`(SSE) |
| `web/` | 화면 전부 (정적). `js/config.js` 가 모든 수치의 단일 출처 |
| `web/replay/` | 실제 실행 기록 34편 — **손으로 만들지 않는다** |
| `runs/` | 혼자 하는 대조군 5편 (`길이불일치/` 는 공정성을 어긴 채 뜬 것 — 실패 분석의 근거) |
| `tools/` | [질문검사](tools/질문검사.py) · [녹화목록](tools/녹화목록.py) · [반복분석](tools/반복분석.py) · [팀대혼자](tools/팀대혼자.py) · [배포검증](tools/배포검증.py) |

## 직접 돌리려면

```bash
pip install -r requirements.txt
cp server/.env.example server/.env     # OPENAI_API_KEY 를 채운다

python -m server.pipeline "질문"        # 1회 약 $0.025 · 1~3분
python -u server/baseline.py q1        # 혼자 하는 대조군
python tools/배포검증.py                # 정적 + 서버리스 함수까지 두드린다
```

키는 커밋하지 않는다 (`.gitignore`). 배포판에서는 방문자가 **자기 키**를 넣고,
그 키는 요청 본문으로만 오가며 서버에 저장되지 않는다.

## 이렇게 정한 이유

| 정한 것 | 값 | 왜 |
|---|---|---|
| 절 수 × 절예산 | **5절 × 3건** | 코퍼스가 51건이라 다섯으로 갈라도 절마다 읽을 것이 남는다 |
| 역할 축 | **둘 — 사건 / 작품** | 줄거리를 묻는 질문과 제작·흥행을 묻는 질문은 나눠야 할 갈래가 다르다 |
| 결재 위치 | **② 배정 뒤** | 배정이 틀리면 보고서는 멀쩡해 보인다. 사람이 되돌릴 수 있는 마지막 지점 |
| 지표 | **9개** | 절이 다섯이라 구멍 날 자리가 많다. 「근거 없는 절」은 전체 평균에 묻힌다 |

명찰(역할)은 n=1 표에서 **다섯 질문 전부 끈 쪽이 높게** 나왔다. 그런데 칸당 3회로 다시 재니
차이(12~13%p)가 **잡음(14.3%p)보다 작았다.** 그래서 사전등록대로 **명찰 기능은 남기고
기본값도 켠 채** 둔다 — 못 정했다고 적는 것이 맞다 ([`REPORT.md`](REPORT.md) 5장).
