## 📖 프로젝트 소개

마블 영화(MCU)에 대해 **답이 문서 한 건에 다 들어 있지 않은 질문**에 답하는
에이전트입니다. 예를 들어 "인피니티 스톤을 둘러싼 주요 사건들은 무엇이고, 각각의
원인은 무엇인가?" 같은 질문은 스톤 여섯 개가 각기 다른 영화에 흩어져 있어 문서
하나로는 절반도 답할 수 없습니다.

모은 자료는 **51건 · 1,543,251자**로, AI가 한 번에 볼 수 있는 양(gpt-4o-mini 기준
약 51만 자)의 **3배**입니다. 그래서 **나눠서 읽고, 나눠서 쓰고, 이어 붙이는** 구조를
만들고, 이 분업을 **신문사 편집국**에 비유했습니다.

```
① 기획 → ② 배정 → 🔏 결재 → ③ 조사 ×5 → ④ 점검 →(↺ ②로)→ ⑤ 종합 → ⑥ 평가
편집장    편집장     당신      기자 5명 동시   편집장              편집장     계량 담당
```

**기자가 읽은 원문은 기자 밖으로 나오지 않습니다.** 편집장은 기자가 쓴 원고만 받지
원문을 다시 읽지 않습니다.

그리고 ② 배정이 끝나면 **사람이 한 번 끼어듭니다** — 목차와 배정을 보고 승인하거나
반려합니다. 배정이 틀리면 보고서는 멀쩡해 보이기 때문에, 사람이 되돌릴 수 있는
마지막 지점을 여기 두었습니다.

> 왜 이렇게 만들었는지, 실제로 돌려 보니 어땠는지, 무엇을 틀렸는지는
> **[REPORT.md](REPORT.md)** 에 있습니다.

## ✨ 주요 기능

- [x] 위키백과 자동 수집으로 코퍼스 구축 (51건 · 154만 자 · 문서 간 링크 포함)
- [x] LangGraph 6단계 파이프라인 — 기획 → 배정 → 조사 ×5 → 점검 → 종합 → 평가
- [x] **사람 결재 게이트** — 배정이 끝나면 멈추고, 반려하면 목차부터 다시 짭니다
- [x] 컨텍스트 격리 — 원문은 기자 안에서만 소비하고, 그 비율을 매번 측정합니다
- [x] 정답표·판정 모델 없이 재는 **지표 9개** + 0이어야 하는 「그물」 2개
- [x] 절제 실험(장치 끄기) · 반복 측정 · **혼자 하는 비교군**까지 3중 검증
- [x] 사전등록 — 판정 규칙을 먼저 커밋하고, 3회가 안 차면 판정 거부
- [x] 아이소메트릭 사무실 데모 — 의존성 0 Canvas, **API 키 없이 기록 34편 재생**

## 🚀 시작하기 (Getting Started)

### Prerequisites (사전 준비)

- **Python 3.10 이상** (개발·테스트는 3.14 기준)
- **OpenAI API 키** — 직접 실행할 때만 필요합니다
- 화면만 볼 거라면 **아무것도 설치하지 않아도 됩니다** (표준 라이브러리만 씁니다)

### Installation (설치 방법)

```bash
# 레포지토리 클론
git clone https://github.com/elfinnani-byte/mcu-deep-research.git
cd mcu-deep-research

# 가상환경 생성 및 활성화
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS · Linux

# 패키지 설치
pip install -r requirements.txt
```

`server/.env` 파일을 만들고 API 키를 넣습니다 (`server/.env.example` 참고):

```
OPENAI_API_KEY=sk-...
```

`.env` 는 `.gitignore` 에 걸려 있어 커밋되지 않습니다.

## 💡 사용법 (Usage)

### 화면 보기 — 키 없이

실행 기록 34편이 저장소에 들어 있으므로 **설치 없이** 바로 볼 수 있습니다.

```bash
cd web && python serve.py      # http://127.0.0.1:8765
```

정적 파일만 있으면 되므로 아무 웹서버나 됩니다. `serve.py` 는 캐시를 끄고,
배포판의 서버리스 함수(`api/*.py`)를 **같은 코드로** 로컬에서도 돌립니다.

화면은 셋으로 나뉩니다.

| 탭 | |
|---|---|
| **재생** | 기록 34편을 **질문 × 설정** 두 축으로 골라 대조군끼리 견줍니다 |
| **라이브** | 본인 키를 넣고 질문을 직접 돌립니다. 키는 **이 브라우저에만** 저장됩니다 |
| **설정** | API 키 입력·삭제 |

주소로도 부를 수 있습니다 — `?replay=` `?tab=` `?speed=` `?auto=0` `?report=1`.
예: [`?replay=q4-역할끔&report=1`](https://mcu-deep-research.vercel.app/?replay=q4-%EC%97%AD%ED%95%A0%EB%81%94&report=1)

### 직접 돌리기 — 키 필요

```bash
python -m server.pipeline "질문"        # 1회 약 $0.025 · 1~3분
python -u server/baseline.py q1        # 혼자 하는 비교군
python -u server/batch.py              # 절제 실험 20편 (약 $0.50)
python -u server/repeat.py             # 사전등록한 반복 측정
```

### 검사·집계 도구

```bash
python tools/질문검사.py     # 질문 세트가 코퍼스·기록과 어긋나는지
python tools/녹화목록.py     # 기록 목록을 폴더에서 다시 만든다
python tools/반복분석.py     # 반복 측정 집계 + 사전등록한 판정
python tools/팀대혼자.py     # 팀 vs 혼자 (차이 옆에 흔들림 폭을 같이 찍습니다)
python tools/배포검증.py     # 배포판이 살아 있는지 (정적 + 서버리스 함수)
```

## 🛠 기술 Stack

- **파이프라인**: LangGraph, LangChain (OpenAI gpt-4o-mini)
- **배포**: Vercel 서버리스 함수(Python) + 정적 호스팅
- **화면**: 의존성 **0** — 순수 Canvas 2D · ES 모듈. 빌드 단계가 없습니다
- **측정**: 표준 라이브러리만. 판정 모델을 쓰지 않고 **코드가 문자열로 셉니다**
