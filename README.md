# 마블 리서치 데스크

질문 하나를 던지면 **AI 편집장이 목차를 짜고, AI 기자 5명이 동시에 자료를 읽어 각자 한 절씩 써 오고,
빈 곳을 찾아 다시 보내는** 딥리서치 에이전트다. 그리고 그 과정을 **아이소메트릭 사무실**로 보여준다.

「8. 딥리서치 에이전트 만들기 — 오케스트레이션」 강의의 6노드 파이프라인을 그대로 구현하고,
MCU 영문 위키백과 **51건 · 154만 자**를 코퍼스로 썼다.

```
① 기획 → ② 배정 → 🔏 결재 → ③ 조사 ×5 → ④ 점검 →(↺ ②로)→ ⑤ 종합 → ⑥ 평가
편집장    편집장     당신      기자 5명 동시   편집장              편집장     최계량
```

**키가 없어도 전부 볼 수 있다.** 실제로 돌린 기록 22편이 들어 있다.

📄 **과제 보고서는 [`REPORT.md`](REPORT.md)** — 무엇을 만들었고, 무엇을 쟀고, **무엇을 틀렸는지**.

## 바로 보기

```bash
cd web && python serve.py      # http://127.0.0.1:8765
```

정적 파일만 있으면 되므로 아무 웹서버나 된다. `serve.py` 는 캐시를 끄고 개발용 캡처 엔드포인트를
하나 더 얹은 것뿐이다.

## 무엇을 볼 수 있나

| | |
|---|---|
| **재생** | 실제로 돌린 기록 22편. `질문 5개 × 설정 4가지` 를 두 축으로 골라 **대조군끼리 견준다** |
| **라이브** | 본인 OpenAI 키를 넣고 질문을 직접 돌린다. 키는 **이 브라우저에만** 저장되고 서버로 가지 않는다 |
| **🔏 결재** | ②배정이 끝나면 **사람이 멈춰 세운다.** 승인하면 기자가 나가고, 반려하면 목차부터 다시 짠다 |
| **대시보드** | 정답표 없이 재는 지표 8개 — 근거·인용·분담·격리 |

주소로 바로 부를 수도 있다 — `?replay=q4-역할끔&report=1` 이면 그 녹화의 보고서가 열린 채로 뜬다
([구조도 6장](docs/구조도.md)).

## 절제 실험

장치를 하나씩 꺼 보고 무엇이 실제로 값을 하는지 잰다 (교재 15강).

| 설정 | 끄는 것 |
|---|---|
| 기본 | — |
| 배정·구역 끔 | 시작 문서를 안 나눠 준다 |
| 역할 끔 | 기자에게 역할을 안 준다 |
| 재위임 끔 | 빈 절을 안 되돌려 보낸다 |

결과는 [`docs/절제실험-결과.md`](docs/절제실험-결과.md).

**⚠ 칸마다 1회씩만 재서, 차이가 흔들림 폭 안인지 아직 구분하지 못한다.**
설정이 똑같은 유일한 2회 반복에서 근거율이 **5.6%p** 움직였다 — 표의 차이 중 절반이 이 폭 근처다.
그래서 반복을 돌리기 **전에** [`docs/사전등록.md`](docs/사전등록.md) 에 판정 규칙을 못박았고,
집계는 [`tools/반복분석.py`](tools/반복분석.py) 가 그 규칙을 코드로 돌린다.

```bash
python tools/반복분석.py        # 표 + H1 판정 (3회가 안 차면 판정을 거부한다)
```

## 구조

```
Source ──> EventQueue ──> Choreographer ──> World ──> Renderer
(기록|라이브)  (배속·정지)     (이벤트→상태)    (상태만)   (캔버스)
```

**의미 이벤트 13종이 유일한 계약이다.** 그림·대사·배치를 바꿔도 녹화를 다시 뜨지 않는다.

| 폴더 | |
|---|---|
| `web/` | 화면 전부 (정적). `js/config.js` 가 모든 수치의 단일 출처 |
| `web/replay/` | 실제 실행 기록 22편 — **손으로 만들지 않는다** |
| `server/` | 파이썬 파이프라인 · 녹화 도구 |
| `api/` | 서버리스 함수 두 개 — `/api/plan`(결재 앞에서 멈춤) · `/api/run`(SSE) |
| `tools/` | [반복분석](tools/반복분석.py) (녹화 집계·판정) · [배포검증](tools/배포검증.py) (정적+함수 확인) |
| `docs/` | [현재 상태](docs/현재-상태.md) · [구조도](docs/구조도.md) · [설계도](docs/설계도.md) · [대본](docs/대본.md) · [사전등록](docs/사전등록.md) |

처음 보는 사람은 [`docs/현재-상태.md`](docs/현재-상태.md) 부터,
그림으로 먼저 보고 싶으면 [`docs/구조도.md`](docs/구조도.md) 부터 읽으면 된다.

## 만든 것과 고른 것

강의에서 **바꾼 것은 넷**이다. 임의로 바꾸지 않았다 — 바꿨다면 그건 실험이 아니라 다른 프로젝트다.

| 바꾼 것 | 강의 | 우리 | 왜 |
|---|---|---|---|
| 폭 | 4절 × 3건 | **5절 × 3건** | 코퍼스가 51건으로 더 크다 |
| 역할 축 | 서사 하나 | **둘 (사건 / 작품)** | 자료가 「작품 × 측면」 두 방향으로 쪼개져 있다 |
| **승인 게이트** | 없음 | **목차 단계에 있음** | 4강 *"배정이 틀리면 보고서가 멀쩡해 보인다"* 를 사람이 잡는 장치 |
| 지표 | 6개 | **8개** (「인용 0곳인 절」·「엉뚱한 곳에 붙은 인용」 추가) | 절이 다섯이라 구멍 날 자리가 더 많다 |

그리고 **17강은 "역할을 나눈 것은 측정에서 아무 차이를 만들지 못했다" 고 결론냈다.**
우리 측정도 같은 방향을 가리킨다. 그 결론을 지울지 남겨 전시할지는 아직 정하지 않았다 —
[`docs/현재-상태.md`](docs/현재-상태.md) 4장에 열어 두었다.
